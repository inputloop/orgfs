This is where the story starts: what the spoke is for.

orgfs stands on other people's free software: a shell, an awk, a web server, an operating system. This spoke exists to show, in the open, which licence each of those carries, as we found it and where we looked.

The page you are reading is the declaration of that spoke. It is also its own explanation. The lines a program reads sit in the small tables under each heading (Org calls them property drawers); the paragraphs around them are for you.

This is an example. The hosts are real names from Corwin's ghostwheel, and what is said about each one is marked as a fact or as an example, so you can tell which is which.
