#+LANGUAGE: en

This is an example. Hold this file identically on every member and each host
derives its own part of the plan from it. Prose such as this paragraph is
ignored by the tool and does not change the spoke's identity.

The paths follow the /spokes layout of the ghostwheel: another host's storage
appears as an sshfs mount under /spokes/HOST/storage, at the same path on
every host that uses it.

:STRIPES: 5
:REPLICAS: 2
:VISIBILITY: public
:END:
